# Wireframes

These are real screenshots captured from the running application during step 10's browser-driven
verification (headless Chromium via Playwright) — not hand-drawn pre-build mockups. Kept here as the
"wireframes/mockups for the main flows" good-to-have (Section 8.2) because they're more honest evidence
of the actual UI than a sketch would be, and were already produced as part of verifying the frontend
works end-to-end (see `web/e2e/full-lifecycle.spec.ts` for the automated version of the same flow).

| File | Flow |
|---|---|
| `login.png` | Role selector (stub auth) |
| `apply.png` | Applicant loan application form |
| `status.png` | Application status tracking |
| `underwriter-queue.png` | Underwriter review queue with decision buttons |
| `offer.png` | Offer view with accept/decline |
